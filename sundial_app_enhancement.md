# Sundial App Enhancement for Mobile Platforms

## Summary

This document outlines the enhancements made to the `sundial.py` app to enable it for mobile platforms.

### Enhancements Made:

- **Framework Chosen**: Kivy was selected as the mobile framework for development.
- **User Interface**: The UI has been redesigned for touch input, creating a more user-friendly experience.
- **Geolocation**: Implemented functionality to automatically determine the user’s latitude.
- **Interactive Guide**: Added an interactive guide with step-by-step instructions for creating sundials.
- **Plotting Improvements**: Utilized libraries for enhanced plotting capabilities.
- **Testing**: Conducted initial tests across various mobile devices to ensure functionality.

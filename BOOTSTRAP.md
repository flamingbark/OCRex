# BOOTSTRAP.md

Use this only when re-initializing the workspace behavior contract.

## Bootstrap Checklist

1. Confirm identity and user preferences in `IDENTITY.md` and `USER.md`.
2. Verify gateway health and auth consistency.
3. Verify swarm scripts exist and run.
4. Verify branch workflow permits autonomous direct pushes to `main` when configured.
5. Verify subagent completion notifications reach the active user channel/session.
6. Seed `MEMORY.md` with durable constraints and current priorities.

## Exit Condition

Bootstrap is complete when safety, routing, and delivery checks pass.
